# Snapshot attribution

Contains information from [The Session](https://thesession.org/), made available
under the [complete TheSession-data license](LICENSE.md). That original text
contains the ODbL and additional contents terms, including its LLM restriction
and accessibility exception. Preserve it with redistributed data.

This is TradMate's adapted, machine-readable catalog as committed for
**TradMate 1.0.3, build 220**. It includes ABC settings, public metadata,
popularity-derived default ratings and stable local catalog IDs. The separate
alias and publisher indexes use the individually pinned sources recorded in
`dataset-manifest.json`; their source dates are not all the same.

The catalog was incrementally updated on 2026-11-09 from upstream commit
`b3e7ba2c4a8f63a9fedb4518c1f0b0cfa279b088`. The alias search index uses commit
`511872c0565b46e929780928a70417694933fdbf` from 2026-11-15. Historical records and references may be
retained when absent or reassigned upstream. The initial 2026-09-19 import's
exact data revision remains unverified; the complete adapted database is
supplied, rather than claimed to be a fresh, exact upstream dump.

Default stars derive from public tunebook counts; they are not five-star user
reviews from The Session. `rating_history` is a bundled historical default
rating snapshot, not users' personal ratings or listening history.
