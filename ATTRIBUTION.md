## Candidate identity

Build 73 candidate metadata is available in [versions/build73.json](versions/build73.json). It identifies a local database only; **the database is not published here**.

The candidate records an import time of `2026-09-19T15:06:59.016222+00:00`. This is not an upstream data revision. The original input revision/hashes, additional alias source, converter revision and rating formula remain unverified. The license commit is a license revision, not a claim about which data commit was imported.

Popularity information originates from tunebook counts. TradMate's displayed stars or sorting indicators may be transformed; they are not described as direct five-star reviews from The Session.
